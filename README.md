# 🎮 Java Labyrinth Game
Un gioco arcade classico sviluppato in Java.

## 🚀 Caratteristiche
- Gestione collisioni con i muri.
- Logica di uscita automatica.
- Interfaccia grafica fluida con Swing.

## 💻 Come giocare
Scarica il file `.jar` e lancia il comando:
`java -jar Labirinto.jar`
